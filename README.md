# API Marcas de Tênis

# Sobre o projeto

Este projeto é uma API simples para cadastro e gerenciamento de marcas e modelos de tênis,a API permite cadastrar, consultar, atualizar e excluir tênis.

# Tecnologias utilizadas

- C#
- ASP.NET Core
- .NET 10
- Minimal API

# Como executar o projeto

É necessário ter o .NET 10 instalado.

No terminal, dentro da pasta do projeto, execute:

```bash
dotnet run --urls http://localhost:5050
